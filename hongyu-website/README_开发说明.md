# 鴻宇株式会社企业展示官网

这是一个日文的高端房地产企业品牌展示网站。现有 React 工程保留深松绿、米白与香槟金风格，展示企业品牌、四项业务、经营理念及品牌价值。工程可独立运行，无需仓库外层素材。

## 运行

要求 Node.js 22.12 或以上版本。从仓库根目录运行：

```powershell
cd hongyu-website
npm ci
npm run dev
```

本地预览为 `http://127.0.0.1:5173/`。验证及生产预览：

```powershell
npm run lint
npm run build
npm run preview
```

构建产物在 `dist/`，生产预览为 `http://127.0.0.1:4173/`。正式部署需要配置 SPA 回退：页面路径返回 `index.html`，静态资源路径返回实际文件。

## 页面与导航

| 顺序 | 路由 | 日文导航 | 内容 |
| --- | --- | --- | --- |
| 1 | `/` | ホーム | 品牌价值、核心业务、四步流程、城市视角、合作优势、品牌愿景 |
| 2 | `/services` | 事業内容 | 四项业务索引、图文介绍、可展开的业务范围 |
| 3 | `/about` | 私たちについて | 企业介绍、经营理念、品牌价值 |

PC、手机和页脚共用 `src/data/site.ts` 的导航顺序。旧 `/contact`、其子路径及 `/contact.html` 仅保留返回首页的兼容重定向，不生成独立页面。未知路径显示 404 页面，并提供返回首页入口。

企业网站没有在线表单、邮件入口、地图、定位、复制功能或相关 FAQ。旧页面与组件、专用样式、联络资料以及表单依赖已移除。全部按钮仅用于页面导航、区块定位或展示内容的展开切换。

## 代码

- `src/pages/`：三个展示页面及 404 页面。
- `src/components/Shared.tsx`：品牌标识、页面首屏、面包屑、导航按钮与品牌横幅。
- `Header.tsx`、`Footer.tsx`：统一导航；页脚只显示品牌、三个页面链接和居中版权。
- `HomeSections.tsx`：首页品牌价值、重点业务与三项业务说明、城市视角、合作优势。
- `Approach.tsx`：洞察、企画、実行、価値向上四步展示，连接线依次点亮，手机端纵向排列；01–04 均位于对应标题旁，连接线末端不显示悬空编号。
- `Accordion.tsx`：仅用于展示业务范围的展开收起。
- `Reveal.tsx`：一次性的滚动渐入。
- `src/data/site.ts`：品牌介绍、导航、四项业务和三个页面的 SEO 信息。
- `src/styles/global.css`：配色、字体、布局、响应式与动效。
- `src/styles/home.css`：仅用于首页中段与紧凑愿景横幅的版式、交互及响应式。
- `src/hooks/useRouteEffects.ts`：路由标题、焦点与锚点滚动。

业务锚点为 `/services#development`、`#investment`、`#management`、`#global`；经营理念入口为 `/about#philosophy`。固定导航的滚动间距已预留。

## 展示规范

主内容使用流式容器：1440px 视口下为 1280px，1920px 下约为 1690px，2560px 下为 2200px。宽屏下分别调整业务分栏、图片高度与正文字号，正文保留合适行长，区块上下间距保持紧凑。

Hero 保留原有容器宽度、主图、位置和电影感动画；首页桌面高度仍为 820–920px。首页愿景横幅桌面高度仍为 290px，手机按内容自适应。首页与业务页的城市横幅使用 `CTA` 的 `imageMode="city-blend"`：独立图片层按原始比例响应式定位，以塔楼顶部为视觉焦点，左右轻微蒙版，左侧深绿渐变，底部淡出为 Footer 的同一深绿色。城市图片层不再使用 cover 或滚动位移，减少裁切和跳动。Footer 主体结构保持不变。

业务卡片支持键盘焦点与鼠标悬停，上移 5px、图片缩放至 1.025、箭头向右移动 4px。品牌价值使用稳妥的优势描述，不展示未经确认的经营数字；城市视角使用静态图文，没有虚构项目名称或空的轮播按钮。流程、区块渐入、导航背景过渡和页内滚动均支持 `prefers-reduced-motion`。手机菜单保留遮罩、Escape、焦点循环及跳转后关闭。

原资料中尚未核实的经营数字已从展示内容与前端数据中撤下。未来如需展示企业实绩，应先由企业确认；本次没有新增经营数字、项目案例、合作伙伴或荣誉。
