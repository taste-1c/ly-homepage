## 工程与页面

`npm run build` 和 `npm run lint` 均通过。开发站点通过 Vite 在本地运行，生产产物通过 `npm run preview` 另行检查。

首页、公司介绍、业务内容、联系我们均可独立访问；四页均具有日文语言标记、独立 title/description 和一个主标题。生产预览直接访问四条路由均返回 200，首屏图片正常加载，未发现运行时错误、失败资源请求或外部资源请求。

`publicDir` 读取外层 `../public`；生产构建含全部 45 个公共图片资源。外层原始资料未作改写。

## 交互检查

- **路由**：Header 各页面跳转、404 页面和返回首页正常。首页四个业务入口切换后保持同一文档，无整页刷新。
- **锚点**：四个业务入口定位准确。桌面目标距窗口顶部 110px，固定导航高 96px；手机目标距顶部 90px，导航高 76px。直接访问、刷新也保留业务锚点。
- **业务详情**：四项详情均可点击展开，Enter 可收起，`aria-expanded` 随状态更新。
- **手机菜单**：按钮展开和收起、Escape 关闭、遮罩关闭、链接跳转后关闭均正常；关闭后恢复滚动和按钮焦点。Tab 与 Shift+Tab 可在菜单操作区循环。
- **FAQ**：点击展开、Enter 收起、空格展开及 ARIA 状态正常。
- **表单**：空表单显示四项必填错误，焦点到首个错误字段；错误邮箱被拦截；更正后错误清除。有效输入明确提示未发送，检查期间没有产生发送请求。隐私政策未提供时同意框禁用。
- **吸顶和回顶**：滚动后 Header 切换墨绿背景，回到顶部按钮正常。
- **动画**：经营数据进入视口前不播放，滚入后达到 `2009年 / 120件+ / 8,400戸 / ¥80億`，再次滚入不重播。减少动态模式直接显示最终值，关闭内容位移动画。
